# Python Problem Solving
This repository contains a curated set of 50 Python coding questions focused on strengthening core programming fundamentals. It demonstrates consistent practice and clear logical thinking through clean and executable Python solutions.

## Purpose
The primary goal of this repository is to build and showcase strong Python foundations required for software development, data analysis, and machine learning roles. The focus is on problem-solving clarity, correctness, and readable code.

## Topics Covered
- Python Basics and Data Types
- Conditional Statements
- Loops and Iterations
- String Manipulation
- Lists, Tuples, Sets
- Dictionaries
- Basic Functions
- Logical and Pattern-Based Problems

## Repository Structure
- `50_python_coding_questions.ipynb`  
  A Jupyter Notebook containing all problems and their corresponding Python solutions in a sequential format.

## How to Use
1. Clone or download the repository  
2. Open the notebook using Jupyter Notebook or Jupyter Lab  
3. Review each problem and solution step by step  
4. Modify or re-solve problems to test understanding  

## Skills Demonstrated
- Strong Python fundamentals
- Logical problem decomposition
- Clean and readable coding practices
- Consistency in hands-on practice

## Tools & Technologies
- Python
- Jupyter Notebook
